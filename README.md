# Europe January 2027

Static GitHub Pages trip planner for Davi & Sarah's first Europe trip: https://davirolim.github.io/europe-january-2027/

- **Flights booked (TAP, 2 adults):** Recife → Lisbon → Madrid on Fri Jan 22, 2027 (arrives Madrid Sat Jan 23, 14:05); Madrid → Lisbon → Recife on Fri Feb 5, 2027 (departs 12:10, arrives 21:55). Carry-on only.

The page is a single `index.html` with no build step and no data files. The old flight price tracker (GitHub Action + `scripts/` + `data/flights.json`) was removed after the tickets were bought. The booking reference stays in email, never in this public repo.
